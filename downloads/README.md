# Download the software and guides

- **arbitrage-finder-windows.zip**: source code, locked dependencies, tests, and all seven English PDFs. Extract it, then follow the included README or setup PDF. This is a source distribution, not a compiled Windows installer.
- **arbitrage-finder-guides.zip**: the seven PDFs only, including a separate setup guide for each bookmaker scraper.
- **SHA256SUMS.txt**: SHA-256 checksums for both archives.

On GitHub, open the ZIP you want and choose **Download raw file**. Individual PDFs are also available in `docs/pdf/` at the repository root. **Code → Download ZIP** downloads the entire repository.

Live bookmaker mappings and coverage remain unverified. The scrapers are configurable tools; these downloads do not establish working feeds for the five bookmakers. The software was tested in Linux; Windows 11 installation is documented.
